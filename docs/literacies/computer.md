# 💻 Computer Literacy

Computer Literacy teaches students how computers work and how to use them responsibly.

## Why it matters

Children use digital tools every day. Understanding basic computer systems helps them move from passive users to more thoughtful and capable participants.

## What students learn

- what computers do and how instructions are carried out
- how software, hardware, and networks fit together
- how to use digital tools safely and responsibly
- how to ask informed questions about technology
