# 💰 Financial Literacy

Financial Literacy teaches students how money works, how spending decisions affect the future, and how to build healthy financial habits.

## Why it matters

Money affects daily choices, future plans, and opportunities. Early practice with value, saving, trade-offs, and planning helps children build useful habits over time.

## What students learn

- how money is used to exchange value
- how saving and spending create different outcomes
- how to think about needs, wants, and trade-offs
- how habits can shape future choices
