# Labels Help Future-You

**Short summary:** Labels help people find and understand information later.

## Big idea

A label is a name that tells future-you what something is. "Stuff" is usually not a helpful label. Folder names, notebook titles, diagram labels, source names, and digital filenames are all labels — and they can be changed when they stop helping.

## Why it matters

Today-you knows exactly what "notes" means. Future-you, three weeks from now, does not. A few extra seconds of naming saves minutes of hunting — and sometimes saves the work itself from being lost.

## Kid-friendly explanation

A label is a clue for future-you, like a note on a treasure map. If the clue says "thing," it does not help. If it says "science notes — water cycle diagram," future-you has a map straight to the treasure.

## Tool: the Future-You Label Test

> - Will I know what this is later?
> - Does the label say the topic?
> - Does it say the type of thing?
> - Does it need a date or version?
> - Is it short enough to use?
> - Would someone else understand it?

## Activity: Rename the Mystery Files

Improve these labels so future-you could find them:

- `stuff`
- `new doc`
- `notes`
- `project final final really final`
- `pic`
- `thing for class`

Good patterns to aim for:

- `media-source-checks-week-10`
- `water-cycle-diagram-v2`
- `decision-journal-bike-choice`
- `budget-practice-wants-needs`
- `scratch-game-sprite-notes`

## Discussion questions

- Why do labels matter later?
- What makes a label too vague?
- When might a date or version help?
- How can a label help someone else?

## Try it this week

Rename one file, folder, page, or note so future-you can find it faster.

## Adult note

Naming is a skill. Avoid shaming messy filenames — teach a repeatable pattern instead: topic + type + date/version if needed.
