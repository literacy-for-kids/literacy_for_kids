# Notes Are Tools, Not Transcripts

**Short summary:** Notes should help you use information later. They do not need to capture every word.

## Big idea

A note is a tool: it can help you remember, explain, compare, ask a question, or find a source again. Copying every word can actually make notes *less* useful — the useful parts drown in the transcript.

## Why it matters

Useful notes often include keywords, an example, a question, a quick sketch, and where the information came from. Notes can be messy while thinking and cleaned up later if needed — and different people use different note styles. What matters is whether future-you can use them.

## Kid-friendly explanation

A note is not a photograph of a lesson. It is a tool you take with you. A hammer, a flashlight, and a map are different tools for different jobs — and notes can take different forms too: a few words, a sketch, a question, an arrow diagram.

## Tool: the Useful Notes Check

> - What is the big idea?
> - What are 2–3 key words?
> - What example helps?
> - What question do I still have?
> - Where did this information come from?
> - What will future-me need?

## Activity: Transcript or Tool?

Compare two fictional notes on the same topic:

1. A copied paragraph with every word from the source.
2. A short note with the big idea, one example, one question, and the source.

Ask: which one helps future-you more, and why? What could be added to the transcript to make it a tool?

## Discussion questions

- Why might copying every word feel safe?
- What makes a note useful later?
- When might a diagram be better than a sentence?
- What should you include so you can find the source again?

## Try it this week

Take one tiny note using big idea + example + question.

## Adult note

Do not grade notes by neatness alone. Ask whether the note helps the child use the information later — a scribbled note that works beats a beautiful transcript that doesn't.
