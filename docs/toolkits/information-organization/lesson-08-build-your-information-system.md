# Build Your Information System

**Short summary:** A small information system helps you sort, label, connect, track, and find information without needing a perfect setup.

## Big idea

An information system can be tiny: a place, some labels, a few categories, and a way to find things again. Digital and paper systems both count — and the best system is the one you actually use.

## Why it matters

Without a system, every pile has to be re-sorted from scratch, every file re-hunted, every source re-found. A small system does that work once. And a system is allowed to change when it stops helping — that is maintenance, not failure.

## Kid-friendly explanation

Think of a small toolbox with a place for each tool. It does not need to be fancy — it needs to be somewhere you can reach, with labels you understand, so the tool you need comes back to your hand when you need it.

## Tool categories

Pick tools that fit you:

- **Sorting tools** — the First Sort
- **Category tools** — the Category Check
- **Label tools** — the Future-You Label Test
- **Example/non-example tools** — Example / Non-Example / Why
- **Note tools** — the Useful Notes Check
- **Visual organizer tools** — Choose the Shape
- **Source/evidence tools** — Claim / Source / Evidence / Question
- **Digital organization tools** — filename patterns, folder categories, versions
- **Find-it-again tools** — one home per kind of thing

## Activity: Build My Small System

Create a simple information system:

- What kind of information am I organizing?
- What is it for?
- Where will it live?
- What categories will I use?
- What labels will help?
- How will I track sources or locations?
- How will I find it later?
- When will I clean or adjust it?

## Discussion questions

- Why should a system be small enough to use?
- What makes a system too complicated?
- How do you know when a system is helping?
- When should a system change?

## Try it this week

Choose one small pile — paper, notes, files, ideas, bookmarks, or sources — and build a simple system for it.

## Adult note

Do not confuse neatness with usefulness. A child's system may look different from an adult's system and still work. Ask: "Can you find and use what you need?"
