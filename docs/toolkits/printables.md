# Shared Toolkit Printables

Quick-reference cards from all five Shared Toolkits, gathered in one place. Every card can be copied, printed, rewritten by hand, taped into a notebook, used during a lesson, or kept nearby for real moments. You do not need the full toolkit to use a card — grab the one that fits today.

:::caution Everyday tools, not a replacement for support
These cards support everyday skills. They do not replace trusted adults, qualified professionals, medical care, legal advice, therapy, disability support, or emergency help.
:::

## Coping Skill Cards

Cards for noticing body clues, pausing, grounding, breathing, resetting the body, checking thoughts, asking for help, and building a coping menu.

[Printable Coping Skill Cards](./coping-skills/printables.md)

## Communication Skill Cards

Cards for listening, clarifying, explaining thinking, disagreeing respectfully, asking for help, using feedback, and repairing misunderstandings.

[Printable Communication Skill Cards](./communication/printables.md)

## Problem Solving Cards

Cards for naming problems, sorting facts from guesses, breaking problems down, brainstorming options, trying safe steps, observing results, adjusting, and asking for help.

[Printable Problem Solving Cards](./problem-solving/printables.md)

## Learning Cards

Cards for forgetting checks, remembering practice, mistakes as data, teach-back, better learning questions, practice plans, and support.

[Printable Learning Cards](./learning-how-to-learn/printables.md)

## Executive Function Cards

Cards for clarifying the job, making the first step tiny, using checklists, estimating time and energy, prioritizing, handling distractions, restart bookmarks, done-enough checks, and support.

[Printable Executive Function Cards](./executive-function/printables.md)

## Collaboration Cards

Cards for shared goals, roles, fair work, check-ins, disagreement, group repair, finishing together, giving credit, and asking for support.

[Printable Collaboration Cards](./collaboration/printables.md)

## Information Organization Cards

Cards for sorting information, choosing categories, labeling clearly, comparing examples and non-examples, taking useful notes, choosing diagrams/timelines/tables, tracking sources and evidence, building a small information system, and asking for support.

[Printable Information Organization Cards](./information-organization/printables.md)

## Which printable should I start with?

| Situation | Printable set to try |
|---|---|
| Big feelings, stress, or shutdown | Coping Skill Cards |
| Misunderstanding, disagreement, or asking for help | Communication Skill Cards |
| Something feels confusing, broken, or too big | Problem Solving Cards |
| A child is trying to remember, practice, or improve | Learning Cards |
| A task is hard to start, organize, track, or finish | Executive Function Cards |
| Group work, shared projects, unfair work, disagreement, or finishing together | Collaboration Cards |
| Messy notes, scattered sources, unclear categories, lost files, or ideas that need sorting | Information Organization Cards |
