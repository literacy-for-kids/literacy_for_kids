# Build Your Start-Finish Plan

**Short summary:** A personal start-finish plan helps you choose tools when a task feels big, blurry, distracting, or hard to restart.

## Big idea

Different tasks need different tools. The goal is not a perfect planner — it is a few reliable tools you can actually find and use when a task feels stuck.

## Why it matters

When a task feels overwhelming, it helps to already know your move: what to do when it is blurry, when starting is hard, when there are too many steps, or when you get interrupted. A plan you actually use beats a fancy one you ignore.

## Kid-friendly explanation

A start-finish plan is like a small toolbox you carry for tasks. You do not need every tool — just a few you trust, kept where you can reach them when things get hard.

## Tool categories

Pick tools that fit you:

- **Start tools** — Job Clearer, Tiny First Step
- **Checklist tools** — a short, ordered list
- **Time/energy tools** — Guess / Actual / Next Guess
- **Priority tools** — Must / Should / Could
- **Focus tools** — Notice / Move / Return, a timer, a quiet spot
- **Restart tools** — Restart Bookmark
- **Help tools** — asking a trusted person, reminders
- **Done-enough tools** — checking the purpose

## Activity: Build My Start-Finish Plan

Fill in your own plan:

- When a task is blurry, I will ___.
- When starting feels hard, I will ___.
- When there are too many steps, I will ___.
- When I lose track, I will ___.
- When I get interrupted, I will ___.
- When I need help, I will ___.
- When I am checking done, I will ___.

## Discussion questions

- Which tool helps you start?
- Which tool helps when there are too many steps?
- Which tool helps when you get interrupted?
- Which tool do you want to try first?

## Try it this week

Choose one start-finish tool and use it on a real task.

## Adult note

Let kids customize. A plan they actually use matters more than one that looks complete. If a tool fails, treat it as data — swap it, do not scold.
