# Roles Make Work Visible

**Short summary:** Roles help people see who is doing what. Visible jobs reduce guessing, taking over, and being left out.

## Big idea

A role is a visible job in the group. When roles are named, nobody has to guess who is doing what — and nobody quietly ends up with everything or nothing.

## Why it matters

Without roles, groups drift into two failure modes: one person takes over, or everyone assumes someone else is doing it. Roles can rotate, should match the goal, and should not trap someone in a job they hate every time. Leadership is not the same as doing all the talking, and helping is not the same as taking over.

## Kid-friendly explanation

A soccer team does not work if everyone chases the ball to the same spot. Different positions cover different parts of the field — and every position is playing the same game. Group roles work the same way.

## Tool: the Role Check

> - What roles do we need?
> - Who is doing each role?
> - What does each role actually do?
> - Does anyone need help?
> - Should roles rotate?

Example roles: materials manager, time checker, recorder, presenter, question asker, evidence tracker, builder, tester, encourager, cleanup lead.

## Activity: Role Match

For each group task, choose 3–4 useful roles from the list (or invent better ones):

- build a model
- prepare a presentation
- run an environmental audit
- compare media sources
- plan a civic proposal
- practice a mock trial

## Discussion questions

- Why can roles prevent confusion?
- When can roles become unfair?
- What is the difference between leading and taking over?
- What role helps you contribute well?

## Try it this week

In one group activity, name the roles before starting.

## Adult note

Watch for roles becoming social traps. Do not always assign quiet kids to recorder or loud kids to presenter. Help groups rotate roles and share power — the point of a role is visibility, not a permanent label.
