# Build Your Collaboration Plan

**Short summary:** A collaboration plan helps a group choose tools before shared work gets confusing.

## Big idea

Groups can prepare before problems happen. A collaboration plan does not need to be complicated — it just needs to cover the goal, roles, fair work, check-ins, disagreement, repair, finishing, and when to get help.

## Why it matters

Most group problems are predictable: blurry goals, invisible work, silent unfairness, unhandled disagreement, and messy endings. A short plan made *before* starting means the group already knows its move when one of those shows up. And a plan that is not helping should change — that is part of the plan too.

## Kid-friendly explanation

A collaboration plan is like agreeing on the rules of a game before you play. You do not wait until the middle of the game to argue about what counts as a goal — you decide together at the start, so the playing part stays fun.

## Tool categories

Pick tools that fit your group:

- **Shared goal tools** — the Shared Goal Frame
- **Role tools** — the Role Check
- **Fair work tools** — the Fair Work Check
- **Check-in tools** — the Three Check-In Questions
- **Disagreement tools** — the Disagree and Build Frame
- **Repair tools** — the Group Repair Check
- **Finish tools** — the Finish Together Check
- **Help/support tools** — a trusted adult, and knowing when to ask

## Activity: Build Our Collaboration Plan

Fill in a simple plan together:

- Our shared goal is ___.
- Done looks like ___.
- Our roles are ___.
- We will share work by ___.
- We will check in by asking ___.
- If we disagree, we will ___.
- If it gets messy, we will ___.
- We will finish by checking ___.
- We will ask for help if ___.

## Discussion questions

- Which collaboration tool helps before starting?
- Which tool helps when work feels unfair?
- Which tool helps when people disagree?
- Which tool helps the group finish?

## Try it this week

Use one collaboration tool in a real shared activity.

## Adult note

Let kids practice collaboration with fictional or low-stakes examples before emotionally loaded situations. Group skills improve when they are visible and practiced — and a plan the group actually made together beats a perfect plan handed to them.
