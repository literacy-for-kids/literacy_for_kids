# Disagree and Keep Building

**Short summary:** Disagreement can improve shared work when the group stays respectful and focused on the goal.

## Big idea

Disagreeing is not the same as attacking, and agreement is not required for every idea. The goal is not to "win" the group — it is to make the shared thing better. Useful disagreement points back to the shared goal.

## Why it matters

Groups that never disagree usually produce the first idea anyone said out loud. Groups that disagree carefully — comparing options, testing ideas, combining parts — usually produce something better. But disagreement only works when it stays about the work, not about the person.

## Kid-friendly explanation

In a workshop, people shape the project — sanding an edge here, swapping a part there. Disagreement can be a shaping tool: "that edge is rough" makes the project better. It stops being a tool when someone uses it as a weapon: "you are bad at building."

## Tool: the Disagree and Build Frame

> - I see it differently because ___.
> - My concern is ___.
> - How does this help our shared goal?
> - Could we test both ideas?
> - Could we combine parts?
> - Do we need help deciding?

## Activity: Disagree or Attack?

Sort each statement:

- "That idea won't work because the poster needs to be readable from far away."
- "That's dumb."
- "I like part of your idea, but I'm worried about time."
- "Nobody should listen to you."
- "Can we test both?"
- "What if we combine them?"

Then rewrite the attacks as real disagreements — or decide they should not be said at all.

## Discussion questions

- Why can disagreement be useful?
- What makes disagreement unsafe or disrespectful?
- How can a group return to the shared goal?
- When should a trusted adult step in?

## Try it this week

When you disagree, try: "My concern is ___ because our goal is ___."

## Adult note

Do not force kids to accept harmful comments as "different opinions." Productive disagreement is respectful and safe. If disagreement becomes cruel, targeted, or threatening, that is no longer collaboration — it is a situation for a trusted adult.
