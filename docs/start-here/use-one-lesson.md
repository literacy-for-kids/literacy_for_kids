# Use One Lesson

You do not need to start at Week 1. You can use any single lesson as a conversation, an activity, or a mini-toolkit — and stop there.

## The 20-minute version

| Time | What to do |
|---|---|
| 2 minutes | Read the title, short summary, and big idea |
| 4 minutes | Explain the kid-friendly example |
| 7 minutes | Try the activity or tool |
| 5 minutes | Discuss 1–2 questions |
| 2 minutes | Choose one tiny "try it this week" move |

## The 10-minute version

1. Read the big idea.
2. Use one fictional example.
3. Ask one question.
4. Pick one tiny next move.

## The 45-minute version

1. Big idea
2. Tool or framework
3. Activity
4. Pair or small-group discussion
5. Reflection
6. Try-it-this-week plan

## Use fictional examples first

Fictional examples let kids practice a skill without being put on the spot. Every lesson works with them:

- a pretend group project
- a pretend budget
- a pretend source-checking problem
- a pretend rule disagreement
- a pretend messy folder
- a pretend health routine
- a pretend environmental audit

## How to adapt a lesson

- Skip sections that do not fit.
- Read aloud if needed.
- Let kids draw instead of write.
- Use sticky notes or cards.
- Let kids answer with fictional examples.
- Use only the printable card.
- Stop if the conversation becomes unsafe or too personal.
- Come back later — lessons do not expire.

## After the lesson

Ask:

- What idea should we remember?
- What tool helped?
- What would future-you need?
- What is one tiny thing to try?
- Do we need adult or professional support for anything bigger than a lesson?

## Good first single lessons

- **A first Shared Toolkit lesson** — every toolkit's overview page lists its eight lessons in order; Lesson 1 is always a safe entry. Browse them from [Use Shared Toolkits](./use-shared-toolkits.md) or the [Shared Toolkits overview](../toolkits/intro.md).
- **One domain intro lesson** — each curriculum site starts with an introduction and a Week 1 built as a first-time experience. Pick a curriculum from [Choose a Literacy](./choose-a-literacy.md).
- **One printable card** — the fastest possible start. See the [Shared Toolkit Printables](../toolkits/printables.md).
