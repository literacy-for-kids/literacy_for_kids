# Start Here for Teachers and Facilitators

Literacy for Kids is designed so you can use one lesson, one short sequence, or one Shared Toolkit without adopting the entire project at once.

## Who this page is for

- classroom teachers
- librarians
- homeschool co-op leaders
- after-school facilitators
- club leaders
- tutors and mentors
- enrichment program leaders
- parents running small groups

No special training is required. Every lesson is written to be facilitated by a thoughtful adult, not a subject-matter expert.

## The basic facilitation pattern

1. Name the big idea.
2. Use a fictional or low-stakes example.
3. Let kids try the tool.
4. Discuss what the tool helps with.
5. End with one tiny next use.

## Session lengths

| Time available | What to do |
|---|---|
| 10 minutes | Use one printable card and one fictional example |
| 20 minutes | Run one lesson lightly |
| 30 minutes | Lesson + activity + discussion |
| 45 minutes | Lesson + activity + reflection or share-out |
| Multiple sessions | Follow a curriculum sequence or toolkit sequence |

## Facilitation norms

- Use fictional examples first.
- Let kids pass on personal sharing.
- Keep discussion concrete.
- Praise useful thinking, not perfect answers.
- Treat confusion as information.
- Let kids draw, talk, sort, move cards, or use sticky notes.
- Do not grade vulnerability.
- Do not ask children to disclose private family, health, legal, financial, or social details.
- Build in quiet options.
- Respect disability, language, sensory, and access needs.
- Follow your organization's safety and reporting policies.

## Choosing a starting path

| Setting | Good starting point |
|---|---|
| One-time library program | A Shared Toolkit lesson or printable |
| Weekly enrichment group | One domain literacy sequence |
| Homeschool unit | [Choose a literacy](./choose-a-literacy.md) + matching toolkits |
| Classroom advisory / SEL-adjacent block | Coping, Communication, Collaboration, Executive Function |
| Media or news discussion group | Media Literacy + Information Organization |
| Robotics or coding club | Computer Literacy + Problem Solving + Collaboration |
| Environmental club | Environmental Systems + Collaboration + Information Organization |
| Student government / civic club | Civic Literacy + Communication + Collaboration |

## How to avoid turning it into a lecture

The lessons work best as practice, sorting, discussion, and reflection — not adult monologues. Useful facilitator moves:

- "What do you notice?"
- "What information would help?"
- "What is one example?"
- "What is one non-example?"
- "What would make this safer or clearer?"
- "What would future-you need?"
- "What is one small next step?"

## Safety, privacy, and support

:::caution Educational lessons, not crisis or professional support
These lessons are educational tools. They do not replace therapy, medical care, legal advice, disability services, school support plans, safeguarding procedures, or emergency help. Use fictional examples whenever personal examples feel private or risky. Follow your school, library, organization, or program policies for safety, privacy, accessibility, reporting, and family communication.
:::

## Group-size notes

- **One child:** use discussion and drawing.
- **Pair:** use role cards or compare examples.
- **Small group:** use sorting cards, roles, or shared notes.
- **Large group:** use a fictional scenario and quick share-outs.
- **Mixed ages:** let older kids explain examples; let younger kids sort, draw, or choose cards.
