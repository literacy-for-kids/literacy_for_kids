# Start Here

Literacy for Kids is a collection of practical, no-prep lessons that help kids ages 8–12 understand the systems they live inside — computers, money, decisions, media, civic life, law, relationships, health, and the environment — and practice the shared skills that help them use that understanding.

Everything is free, open-source, discussion-based, and designed to work in 10–20 minute pieces.

## The two layers

The project has two layers that work together:

| Layer | What it answers | Examples |
|---|---|---|
| **Domain literacies** | What system are we trying to understand? | computers, money, media, civic life, health, environment |
| **Shared Toolkits** | What skill helps kids use that understanding? | coping, communication, problem solving, learning, executive function, collaboration, information organization |

## You do not need to use everything

This project is modular. A parent can use one conversation. A teacher can use one 20-minute lesson. A club leader can use one printable card. A homeschooler can follow a full sequence.

Start with the smallest useful piece.

## A simple rule

> Start with the child's real question, current need, or obvious friction point.

For example:

- worried about online safety → Computer or Media Literacy
- confused by spending choices → Financial or Decision Literacy
- upset after a friendship problem → Emotional & Social Literacy + the Communication or Coping toolkit
- overwhelmed by a project → the Executive Function or Information Organization toolkit
- doing group work → the Collaboration toolkit
- asking "who makes the rules?" → Civic or Legal Literacy
- worried about health habits → Health Systems Literacy
- worried about climate, recycling, or waste → Environmental Systems Literacy

## Safety and privacy

:::caution Educational tools, not crisis support
Literacy for Kids offers educational lessons and discussion tools. It does not replace therapy, medical care, legal advice, disability support, school policies, or emergency help. Use fictional examples whenever personal examples feel too private — they work fine. If a situation feels unsafe, serious, or too big for a normal lesson, involve a trusted adult or qualified professional.
:::
