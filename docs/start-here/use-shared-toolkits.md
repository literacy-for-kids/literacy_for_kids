# Use Shared Toolkits

Shared Toolkits are short, reusable skill lessons. They are not separate subjects kids have to master before starting the curricula. They are tools you can pull in when a lesson, project, conversation, or real-life moment needs one specific skill.

## Pick one, not all seven

The point is not to stack every toolkit onto every lesson. Pick the one tool that helps with the current friction point. Each toolkit has a short overview, eight 10–20 minute lessons, and printable cards.

## The seven Shared Toolkits

| Toolkit | Use when… | Start |
|---|---|---|
| 🧰 Coping Skills | feelings are big, the body is tense, or a pause would help | [Toolkit](../toolkits/coping-skills/intro.md) |
| 💬 Communication | kids need scripts for asking, explaining, listening, disagreeing, or repairing | [Toolkit](../toolkits/communication/intro.md) |
| 🛠️ Problem Solving | something feels stuck, confusing, broken, unfair, or too big | [Toolkit](../toolkits/problem-solving/intro.md) |
| 📚 Learning How to Learn | kids need help practicing, remembering, using mistakes, or getting feedback | [Toolkit](../toolkits/learning-how-to-learn/intro.md) |
| 🗂️ Executive Function | a task is hard to start, organize, prioritize, recover from, or finish | [Toolkit](../toolkits/executive-function/intro.md) |
| 🤝 Collaboration | shared work needs goals, roles, fair work, check-ins, repair, or credit | [Toolkit](../toolkits/collaboration/intro.md) |
| 🗃️ Information Organization | notes, sources, examples, files, ideas, or evidence need sorting and labels | [Toolkit](../toolkits/information-organization/intro.md) |

## Quick examples

- A child is overwhelmed by a project → Executive Function + Information Organization
- A group is arguing about who does what → Collaboration
- A child is embarrassed after a mistake → Coping + Learning How to Learn
- A child cannot explain what they need → Communication
- A lesson has too many facts → Information Organization
- A plan is not working → Problem Solving
- A media claim needs tracking → Information Organization + Media Literacy
- A civic group project needs roles → Collaboration + Civic Literacy

## Printable cards

The [Shared Toolkit Printables](../toolkits/printables.md) page collects every card set in one place. Printable cards are the fastest way to use a toolkit without teaching a full lesson — print one, tape it in a notebook, and use it when the moment comes.

## What the toolkits are not

- not therapy
- not discipline scripts
- not a behavior compliance system
- not a replacement for accommodations or professional support
- not a requirement to disclose personal experiences
- not something to pile onto every page

## Good starting path

1. Choose one current friction point.
2. Pick one matching toolkit.
3. Use one lesson or printable card.
4. Try one small move.
5. Come back later if it helps.
