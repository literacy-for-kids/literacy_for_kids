# Start Here for Parents and Caregivers

You do not need to run a full curriculum to use Literacy for Kids. You can use one lesson, one discussion question, one printable card, or one Shared Toolkit when a real-life moment comes up.

## Three easy ways to start

### 1. Start with a real question

Kids hand you starting points all the time:

- "Why do ads try to trick me?"
- "How do I know if something online is true?"
- "Why can't I buy everything I want?"
- "Why do people make rules?"
- "Why does my body feel weird when I'm nervous?"
- "Why do adults care about sleep?"
- "Why is recycling complicated?"

Each of those questions maps to a literacy — see [Choose a Literacy](./choose-a-literacy.md).

### 2. Start with a friction point

Everyday friction is also a starting point:

- overwhelmed by a school project
- messy files or notes
- an argument with a friend
- group work frustration
- forgetting instructions
- spending confusion
- news or social media confusion
- big feelings around mistakes

### 3. Start with one Shared Toolkit

If the need is a skill rather than a topic:

- big feelings → Coping
- misunderstanding → Communication
- stuck problem → Problem Solving
- forgetting or practicing → Learning How to Learn
- hard to start or finish → Executive Function
- group work → Collaboration
- messy information → Information Organization

## A 15-minute home version

1. Pick one lesson or printable.
2. Read the big idea together.
3. Use a fictional example first.
4. Ask one discussion question.
5. Choose one tiny "try it this week" move.

That is a complete use of the project. You are done.

## Use fictional examples first

Kids may shut down if every lesson becomes "tell me about your real problem." Fictional examples let kids practice the skill without being put on the spot:

- "A kid named Sam has three tabs open and lost the source."
- "A group is arguing about who should present."
- "A kid wants to buy a toy but is saving for something bigger."
- "A friend keeps interrupting during a project."

If your child volunteers a real example, great — but never require one.

## How to choose the right starting point

| What you notice | Try this |
|---|---|
| Big feelings, shutdown, stress, or frustration | [Coping Skills Toolkit](../toolkits/coping-skills/intro.md) |
| Misunderstanding, arguing, or asking for help | [Communication Toolkit](../toolkits/communication/intro.md) |
| "I'm stuck" or "this is too hard" | [Problem Solving Toolkit](../toolkits/problem-solving/intro.md) |
| Forgetting, practicing, or learning from mistakes | [Learning How to Learn Toolkit](../toolkits/learning-how-to-learn/intro.md) |
| Trouble starting, organizing, or finishing | [Executive Function Toolkit](../toolkits/executive-function/intro.md) |
| Group work feels unfair or confusing | [Collaboration Toolkit](../toolkits/collaboration/intro.md) |
| Notes, sources, files, or ideas are messy | [Information Organization Toolkit](../toolkits/information-organization/intro.md) |
| A question about money, media, rules, health, environment, computers, and more | [Choose a domain literacy](./choose-a-literacy.md) |

## What not to do

- Do not turn every lesson into a lecture.
- Do not require personal disclosure.
- Do not force a child to finish a lesson if the real issue is safety, exhaustion, or distress.
- Do not treat the toolkits as therapy.
- Do not use the lessons to prove a child is wrong.
- Do not use "literacy" as another word for compliance.

## When to get more support

If the topic involves serious mental health distress, abuse, bullying, discrimination, medical symptoms, legal problems, unsafe online contact, self-harm, threats, or anything that feels too big for an educational conversation, involve a trusted adult or qualified professional. These lessons are a starting point for understanding — not a substitute for real support.
